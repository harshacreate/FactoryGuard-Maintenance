# FactoryGuard-Maintenance — Predictive Maintenance Prototype

**Sector:** Manufacturing  
**Task:** Binary classification: synthetic near-term equipment failure

Estimates a synthetic failure label from vibration, temperature, pressure, acoustic energy, load, wear, and age. Machine IDs are only used for group splitting.

## Data and provenance

The offline demo uses a deterministic synthetic generator in `factoryguard/data.py`. It does not use or download real records, and no external data license applies. Synthetic output is only a benchmark for this simulator, not evidence of real-world performance.

## Method

- **Baseline:** majority-class prior classifier.
- **Stronger model:** histogram gradient-boosting classifier.
- **Split:** grouped holdout by machine, pipe, camera, or contractor (IDs are excluded from the model inputs).
- **Metrics:** accuracy, balanced accuracy, macro F1, confusion matrix, ROC-AUC, average precision, precision, and recall.
- **Error analysis:** confusion matrix and total misclassification count.

## Limitations

Failure labels are generated by a simplified sensor simulator; no real factory telemetry is used. This is not a safety system or maintenance schedule.

## Run

    python3 -m venv .venv
    . .venv/bin/activate
    python -m pip install -e ".[test]"
    python -m factoryguard.train --seed 42 --samples 2400 --json
    python -m pytest -q

`make setup`, `make train`, and `make test` are shortcuts. Python 3.9 or newer is required.

## Layout and license

- `factoryguard/data.py`: synthetic generator and validation.
- `factoryguard/split.py`: entity-group split.
- `factoryguard/model.py`: baseline, stronger model, metrics, and subgroup diagnostics.
- `factoryguard/train.py`: CLI.
- `tests/`: data, split, model, metric, and CLI checks.
- `.github/workflows/ci.yml`: CI.
